- 实际查看了 [Claude Code 官方产品页](https://claude.com/product/claude-code) 的桌面交互演示：采用低饱和背景、紧凑侧栏、以正文为主的回答区和轻量输入框。页面演示的线程按钮使用 Anthropic 自有无衬线字体，约 13px；本应用使用系统字体，并提高中文阅读字号，不复制品牌字体或素材。
- [Codex 官方介绍](https://openai.com/index/introducing-the-codex-app/) 用于确认会话与侧栏组织方式；页面中的视频未能直接预览，不据此声称还原其视觉细节。
- 尝试查看豆包公开页面，但页面未能正常展示。本版没有把未经核实的豆包界面当作设计依据。

下面的字号、间距、配色是本项目的设计选择，不是这些产品的精确参数。

## 字体与阅读

界面字体使用操作系统无衬线字体。macOS 优先系统 UI 字体及苹方，Windows 提供 Segoe UI 和微软雅黑回退。常规正文使用 400 字重，标签 500，页面标题 600；避免强制细体渲染。

| 用途                 | 默认字号 | 说明                     |
| -------------------- | -------- | ------------------------ |
| 界面基准与设置标签   | 13px     | 可调整至 12–18px         |
| 导航、控件、来源内容 | 13px     | 与界面基准一致           |
| 说明、元信息         | 12px     | 基准减 2px，最低 12px    |
| 对话正文、阅读预览   | 15px     | 基准加 2px，正文行高 1.8 |
| 区块标题             | 16px     | 基准加 3px               |
| 页面标题             | 20px     | 基准加 7px               |

阅读字体选择仅作用于对话正文、来源文字、OCR 结果和阅读预览。导航与设置保持系统字体，避免等宽字体使整个界面难以阅读。旧版未修改的默认偏好升级为 13px 和默认配色；已有自定义偏好保留。typographyVersion 3 标记避免在后续启动时重置用户选择。

## 颜色与布局

共享变量定义在 `apps/desktop/src/shared/styles/tokens.css`；应用布局在 `app/styles.css`，设置特有布局在 `features/settings/settings.css`。

- 默认石墨蓝强调色；鼠尾草绿、靛蓝、琥珀为可选配色。
- 浅色使用白色卡片与淡蓝灰侧栏；深色使用深蓝灰，说明文字同步提高对比度。组件使用语义颜色变量。
- 桌面侧栏 248px，对话与输入框阅读列最大 760px。主内容面板与侧栏分层；首页问候、输入框与三张任务卡集中放置。
- 设置桌面采用左侧分类、右侧内容；窄窗口改为横向分类。控件、分隔线、焦点与保存反馈共用规范。
- 资料库保留真实统计、上传、OCR 与文件操作；对话引用保留原始资料 ID、范围提示和逐次云端图片授权。
- 动画遵守系统减少动态效果设置，键盘焦点可见。

## 本次验证

实际浏览器检查了 1280×850 桌面和 445×820 窄窗口，以及 18px、英文、等宽阅读字体和深色模式。验证了偏好刷新持久化、方向键切换设置分类、设置保存反馈、快捷建议填入、`@` 键盘引用、`/` 命令菜单及图片来源展开。

当前重构与本地权限验收见 [UI 验收记录](ui-access-audit.md)，最新预览在 `docs/previews/refined-*.png`。这些是连接真实本地服务后的应用截图；资料内容为项目演示样本。

## 紧凑字号调整

针对字体偏大反馈，页面标题由 24px 降为 20px，默认界面基准由 15px 降为 13px；导航和按钮使用 13px，对话正文 15px，说明 12px。页面标题栏与资料卡片同步缩短，避免只缩文字而留下大块空白。不使用 CSS zoom 或 transform 缩放页面。
