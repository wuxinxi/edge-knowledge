# 聊天资料引用

引用是聊天的明确资料范围。选择器按已导入资料的标题、文件名或保存路径查找，展示标题和位置，避免一组 `index.md` 无法区分。标题来自现有元数据目录；没有标题的资料回退文件名，不用模型生成名称。

点击“引用资料”打开独立搜索框；直接输入 `@` 也复用相同选择器。每页 20 份，可加载更多，已引用项标记并禁止重复添加。最多 10 份的范围保持原有限制。按方向键选择、Enter / Tab 确认、Esc 关闭；搜索框没有候选时 Enter 不提交聊天问题。失败可重试，搜索切换、关闭、卸载和知识库切换会取消未完成请求，迟到结果不能覆盖当前列表。

输入框显示“当前资料范围”、每份资料的标题和路径，以及移除/清除入口。清除范围不修改未发送的问题，并沿用此前实现的上下文停用规则，避免下次查找偷偷重新带入旧资料。多份引用只在引用区域内滚动，控制输入区高度；路径截短显示时可悬停查看完整位置。打开完整原文所建立的引用也使用同一展示方式。

会话当前范围、每轮已提交引用、可选上下文保存可选 title / path，重启、重试和备份恢复保留。查询请求仍传递真实资料 ID；展示标题和路径不能代替权限身份，执行器继续校验当前知识库归属。旧记录没有这两个字段时兼容文件名。历史消息保留当时的身份标签，不自动改写已经保存的引用。

## 分层

`QueryService.reference_choices` 通过现有 CatalogMirror / DocumentCatalog 查询元数据，复用 QuerySpec 的组合条件、排序和分页。API 只验证请求范围并调用应用服务，renderer 只经过 shared/api/client 获取结果。端点 `/api/libraries/{library_id}/reference-choices` 返回 document_id、filename、title、path、kind、总量及分页位置，不返回正文、检索片段或授权路径之外的新文件。默认 20、最多 50 份；关键词最多 400 字符。资料未导入时不扫描磁盘，也不加载嵌入或生成模型。

## 验收与边界

435 项测试（157 TypeScript、278 Python）、类型检查、静态检查和桌面构建通过。新增回归覆盖同名文件的标题/路径查找、分页与删除、鉴权与知识库隔离、参数上限、快速搜索取消、迟到响应、加载失败重试、键盘操作、草稿保留和会话/备份往返。

浏览器使用明确标注的演示数据与受控 API 响应，验证 25 份同名笔记分页、路径搜索、引用与草稿刷新恢复，以及清除后请求的 document_ids 为空。1280×860 浅色桌面和 760×700 深色英文 18px 检查通过，弹层没有越出窗口，没有页面异常或非预期 API 请求。后端真实目录与存储行为另由测试验证；该浏览器验收不代表真实模型检索质量，未加载模型、上传资料或改动用户笔记。
