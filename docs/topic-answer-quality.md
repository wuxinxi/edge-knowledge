# 主题问答质量：ASR 样例

2026-10-14，用户在助手模式提问“asr 方案有哪些”，期望命中“228M 阿里 SenseVoice 端侧实战！1.3s 极速冷启动：旧安卓手机爆改全离线 AI 助手（第二弹）”。检查本机保存的会话和隔离知识库副本，不向云端发送资料，不修改实际索引和会话。本文只记录诊断结论，不保存笔记正文或生成的回答。

## 原因

- 保存的用户消息模式为 `chat`，回答类型却为 `retrieval`。真实 MiniCPM5 2B 将同一句问题规划为 `search`；执行器直接返回资料数量，没有进入回答生成。
- 候选词项中，“方案”在当前候选里比 ASR 稀有，因而获得更高权重。标题方案、布局方案进入来源；真正的端侧实战笔记虽然余弦为 `0.7481`，且包含 ASR，却因未写“方案”而被覆盖率规则排除。这不是漏导入或缺失向量。
- 去掉问句噪声后，指定笔记排名第六；前五条中有一张图片的 OCR。普通知识问题需要优先使用可供整理的文字笔记，而明确搜图仍应使用图片检索。

## 通用处理

应用层将助手模式中的模型 `search` 视为获取依据的步骤：存在可用文档或联合素材时，继续生成回答。查找模式、明确查找意图、显式查询计划、筛选统计和纯媒体检索保留既有语义，不因这条反馈自动调用生成模型。生成服务仍由选定的 provider 决定，默认本地，失败不自动切到 DeepSeek。

领域层将中英文通用问句词（方案、方法、方式、solutions、methods 等）作为词项噪声，并移除“有哪些”等问句套话。原问题和实际嵌入输入保留；只改善词项召回、覆盖率计算与排序。沿用已有最低相关度、具体标识约束、去重和语义同义检索规则，不增加 ASR 专用分支。

普通助手问答在未指定引用、资料类型或显式计划时，优先选择相关文档/联合素材。只有初次结果包含图片时，才在同一许可范围内补查文字资料；文字资料不足时补充原结果中的图片文字。最终条数仍遵循用户的 top-k 和计划 limit，不扩展权限，不增加上下文条数。

本地与云端规划提示明确区分知识问答和查找原文。生成提示要求直接回答、合并重复方案、说明已记载的差异和限制、标明来源，并区分单设备实测与普遍性能保证。未提供的方案和参数不得补编。
