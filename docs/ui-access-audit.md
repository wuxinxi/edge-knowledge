## 权限范围

授权仅提供所选位置的应用内只读范围。macOS 受保护目录依然受系统权限控制。撤销阻止后续读取，已提交到本地服务的单文件请求可能完成；已入库副本需在知识库中管理。扫描和导入有文件数量、深度、单文件与总量限制。麦克风、摄像头、屏幕录制、通知默认拒绝。Mac App Store 沙盒及签名发行未验收。

## 本地查找与聊天直接预览（2026-10-13）

查找资料继续只访问认证后的本机接口。查询原文字段、找文件/图片/媒体的明确请求，即使从 AI 解读入口发起，也由后端优先返回本地结果，空结果不回退云端；总结、分析、解释仍由用户选择的 AI 解读执行。SSE 增加 execution 信息，回复按真实执行路径显示本地检索或 DeepSeek 解读。OCR 文字送入 AI 解读的提示明确说明会发送文字、不发送原图，避免“不发图”被误读成“不调用云端”。

聊天直接展示前几份匹配资料，图片显示本机预览、媒体显示播放器、普通文档按安全 Markdown 显示每个命中片段。图片 OCR 原文默认收起，保留原始换行与复制，不把图表坐标/标签冒充结构化数据；来源详情复用相同内容组件。关闭的来源弹窗不加载隐藏预览，避免重复读取图片。图表文字不由生成模型伪造整理。图片预览随窗口高度收紧，本地结果完成后定位到回复开头，保留长回答的正常滚动与手动阅读。
