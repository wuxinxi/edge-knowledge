# 完成范围与待办

核对日期：2026-10-13。依据当前源码、测试与验收记录；区分实现缺口、真实服务验收和发行验收。

## 已实现的用户需求

图片查相似图片、图文混合输入、多图联合编码、音视频检索与时间定位、分类、聚类、语义查重及可恢复暂存、8192-token 预算管理均已有实际入口与真实模型样例验收。

多会话及管理、`@` 引用、快捷命令、设置、统一 UI、文件/目录只读授权、手动扫描预览、选择导入与撤销授权已实现。当前默认 UI 13px、页面标题 20px、正文 15px。最新测试与构建结果见开发状态。

这不等于正式商业发行已经完成，也不等于音视频已有转录和生成式理解。样例验收不能代替中文用户语料与大规模性能评测。

## 建议顺序

1. 系统钥匙串与数据备份，先保护已有数据和凭据。
2. 后台任务中心、大目录分页与目录增量索引，形成稳定资料处理流程。
3. 扫描 PDF、媒体转录与带来源总结、对话附件。
4. 用真实语料和真实云端账户验收，再完成安装包与发行测试。
