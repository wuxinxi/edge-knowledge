# 文件夹知识库

知识库是资料集合，一个知识库可连接多个文件夹，也可继续导入单个文件。同一目录可显式连接到不同知识库，索引互相隔离。

## 使用

1. 在桌面应用选择当前知识库，进入“我的知识库”。
2. 在“文件夹来源”点击“添加文件夹”，使用原生选择器连接笔记目录。选择器明确说明只读范围与自动检查行为。
3. 首次扫描子目录并索引支持的资料，显示文件进度、已索引数量与失败原因。来源文件清单保留相对路径，支持搜索与每页 50 条翻页。
4. 桌面应用运行时每 60 秒重新扫描；只有内容 SHA-256 改变的文件重新编码。可点击“立即同步”，或暂停/开启自动同步。
5. “移除来源”停止同步并隐藏连接，原件与已入库资料保留；重新连接相同规范路径和知识库会复用原来源 ID。若要撤销只读访问，进入“本地权限”撤销目录。

文档、图片、音视频复用原有真实索引管线，不调用 DeepSeek。Markdown 文本可检索；当前不解析 Obsidian 双链关系、不自动展开远程附件，也不读取隐藏的 `.obsidian` 配置。

## 更新与删除

目录来源 ID 与相对路径共同确定归属，不同子目录同名文件、不同文件夹以及手动导入互不覆盖。每个变化版本获得独立资料 ID。成功索引新版本后才把旧版本移到回收站；普通写入失败恢复旧活动索引。返回曾经的旧内容或文件删除后重新出现也生成独立版本，避免活动资料与回收站重复使用同一 ID。

仅在完整扫描且没有读取/索引失败时清理缺失文件。清理仅归档此来源的索引，不删除其他来源资料或原文件。超过体积限制或被符号链接替换的已跟踪路径会保留旧索引；无法完整遍历子目录时不执行缺失清理。重试会跳过此前已成功的内容。

手动移入回收站的文件不会因内容未变而自动恢复；修改原文件后会索引新的版本。历史版本可在资料回收站恢复，恢复后可与当前版本同时检索。

## 权限与资源边界

- 页面只传知识库与来源 ID；来源必须经原生目录选择器与现有只读授权建立。实际文件路径和读取只在 Electron 宿主中处理。
- 每次读取复用规范路径、范围、inode、设备、大小、修改时间和有界字节校验。跳过隐藏文件、依赖目录与符号链接。扫描支持最多 32 层子目录。
- 单次来源扫描最多 5000 个支持的文件、100000 个遍历/跳过条目；超限明确报错，已处理资料保留，不清理缺失索引。目前没有继续扫描游标，需要连接更小的子目录。
- 单文档/图片 20 MB，单音视频 200 MB / 60 分钟。来源最多 100 个（含为重新连接保留的来源身份），旧版手动扫描入口仍返回最多 100 个候选。
- 采用每分钟轮询，不依赖文件系统 watcher。应用关闭时不运行；重启自动来源重新扫描并按持久化内容摘要跳过已完成文件。检测时间加实际排队/编码时间才是更新延迟。
- 来源同步串行排队。暂停、移除或撤销会取消后续扫描/读取/网络等待；已提交到后端的单文件推理可能完成。不能将取消等待描述为即时中断模型计算。
- 目录绑定和授权不进入便携备份；已索引原件、向量与回收站快照沿用现有备份。恢复副本需要再次主动连接目录。

当前普通失败回滚已验收；Chroma/素材/SQLite 之间尚没有跨进程写前日志。异常断电或强制杀死后端可能留下待核对版本，不声称具备完整灾难恢复。全局后台任务中心、细粒度推理取消、扫描分页与大规模性能验收仍见待办清单。

## 分层

`features/folders` 展示来源与进度，仅调用共享 API；窄 preload 提供列出、选择、同步、暂停、恢复与移除六项命名操作。主进程校验 sender/frame；`electron/folders.ts` 管理来源绑定、排队、轮询与取消，授权读取委托 `LocalAccess`。

后端 `application/folders.py` 接收字节、来源 ID 和相对路径，负责版本替换、归属与完整清单核对；不读取本机目录。`domain/folders.py` 是纯数据对象，`SourceStore` 是应用端口。`infrastructure/sources.py` 用 SQLite 保存逐文件摘要和索引 ID，按模型隔离；仅 bootstrap 组装实例。目录元数据与原件读写不穿透展示层或后端领域层。

## 验证

自动测试覆盖 130 份嵌套笔记、相同内容跳过、新增/修改/删除、不同来源和知识库隔离、SQLite 重载、写入失败回滚、旧内容重新出现、媒体真实解码、备份兼容、完整扫描约束、暂停、撤销、重新连接与自动定时检查。生产仍使用真实模型；测试端口替身只验证业务行为。

真实 Electron 中已看到用户主动连接的笔记目录与 3410 个候选，后台真实模型开始入库，已导入资料可在工作台选择。首轮全量导入尚在进行，不能把“开始处理”写成“3410 份全部成功”。

## 清空与同步暂停

清空当前库资料时，所有来源暂停，后端同步代次递增。清空前已取得代次的扫描、文件上传与删除核对不能再修改活动索引。恢复回收站资料不会重新启用目录；点击来源“恢复”或显式手动同步后才允许新代次读取。选择部分资料移入回收站不会暂停整个目录，原路径发生修改后仍可同步新版本。
