# 笔记数量与日期统计

年月笔记统计现在由 [通用查询计划与本地执行层](query-engine.md)完成，使用共享 QuerySpec、元数据索引和数据库执行器。旧的专项统计服务已经移除。

简单问题如“2026 年 9 月写了多少篇笔记”可本地快速编译；更复杂的条件在聊天的“筛选与统计”中组合，也可明确开启 AI 模式让 DeepSeek 规划。规划器不计算答案；统计始终由本机数据库执行。

写作、发布、修改、导入日期和目录月份分别保存，不允许用 updatedAt 或导入时间冒充写作时间。缺少日期、缺少数值、缺少完整原文的情况会明确说明。目录月份可提供单独的归档参考，不能证明实际写作日期。

范围是当前库已导入的活动文档或引用集合，每份文档只计一次。同名文件不合并，草稿和提纲只要是该范围里的文档就会包含；图片、音视频和联合素材可用类型条件单独筛选与统计。当前索引不会猜测某个文件是否是正式发布文章。

YAML 文件头部的标题和日期仍以紧凑元数据栏呈现，原文、历史回答和查询条件随会话保存与备份保留。具体支持范围与验证见通用查询文档。
