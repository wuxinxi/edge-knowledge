# 密钥安全、备份恢复与资料回收

2026-10-12。

## 密钥

设置 → 模型 → 输入并保存 API Key。macOS 使用系统钥匙串；Windows 和 Linux 适配器明确选择系统凭据后端，不使用第三方明文回退。当前完成真实验证的平台是 macOS。

凭据账户由当前数据目录的摘要隔离，开发版、浏览器独立服务和正式桌面数据目录互不覆盖。配置仅保存 `credential_override` 与普通参数，API 只返回是否已配置、存储方式及迁移错误，不返回密钥。Key 缓存只在后端内存使用；环境变量密钥仍可作为启动配置，由用户自行管理，应用不把它复制到磁盘。

旧配置迁移：先写入并回读系统凭据，再原子重写配置去掉明文。凭据库不可用或访问被拒绝时保留旧文件，页面明确显示迁移未完成；不继续使用旧明文密钥，也不因保存其他参数而覆盖它。解锁后重新保存密钥可重试。配置写入或凭据写入失败时尝试回滚原凭据，回滚失败会明确提示。

移除密钥会删除本应用当前账户的凭据，并记录空覆盖，避免重新启动后意外启用环境变量密钥。其他程序的系统凭据不受影响。

实现依据：[keyring 官方文档](https://keyring.readthedocs.io/en/stable/)。单元测试使用显式测试适配器；真实 macOS 验收只创建独立的生成测试凭据，验证保存/读取/移除后清理，不使用实际 DeepSeek Key。

## 备份

设置 → 数据与关于 → 创建本机备份，保存 `.edgebackup` 文件。

包含：所有当前模型知识库的活动资料、回收站/暂存资料、切片与向量、规范化图片/缩略图/OCR、已保存的原始文档和媒体、当前设备的有效对话及界面偏好。

排除：API Key、生成服务配置、目录授权、模型权重、系统凭据。备份是未加密 ZIP，界面明确提示资料正文与媒体在文件内，需要保存到可信位置。

早期普通文档只保存了切片，不能据此伪造 PDF/DOCX 原件。备份预览会提示缺失原件数量，仍可恢复文字、来源与索引。此版本起普通文档导入会保存原始字节；图片仍保存去除元数据后的规范化素材。

当前资源边界：压缩文件与展开内容各最多 512 MB，清单最多 64 MB，单素材最多 200 MB，知识库最多 100 个，单库最多 5000 份资料，累计最多 50000 个片段。对话与界面偏好最多 3 MB，最多 500 个对话。超过限制明确报错；尚不是大规模流式备份方案。

## 恢复

1. 选择备份，检查知识库/资料/暂存数量与模型兼容状态。
2. 可选择恢复对话、应用界面偏好；默认保留现有偏好。
3. 点击“恢复为新副本”。创建新的知识库 ID，不覆盖现有资料。

清单版本、字段、重复条目、路径、展开体积、素材摘要、图片格式、片段顺序与向量维度均需通过校验；不会将 ZIP 路径直接解压到文件系统。模型或维度不同会阻止恢复，无法把异构向量混入当前索引。

恢复无需推理。普通写入失败会回滚本次新库和新素材，现有库保留。对话获得新的对话/消息 ID，知识库引用映射到新库，来源文档 ID 保持一致。前端存储配额不足时保留现有对话，提示资料已恢复但对话失败；应保留备份，当前重试会再次创建新副本。

目前恢复是同步事务。异常断电/进程被强制终止的持久化任务恢复、细粒度取消与后台进度属于下一阶段，不在此处冒称已完成。各备份有 SHA-256 完整性检测，但未做签名或加密，不能把摘要当作来源可信证明。

## 资料回收

资料列表的移除操作改为“移入回收站”。“回收站与暂存”页提供恢复，和语义查重暂存共用快照机制：资料不参与检索、活动媒体接口拒绝访问，原件和向量仍保留。恢复重新写入索引，无需重新编码。

现有底层永久删除 API 保留兼容性，正常界面不再调用。回收站不提供清空/永久删除按钮。对话目前仍提供立即撤销以及备份恢复，没有独立持久化对话回收站。

## 分层

- `domain/backup.py`：纯数据快照。
- `application/ports.py`：`CredentialStore`、`BackupCodec` 及仓储快照端口。
- `application/backup.py`：备份范围、模型兼容、恢复副本与回滚。
- `infrastructure/credentials.py`：系统凭据库适配器。
- `infrastructure/backup.py`：版本化 ZIP、模式校验、有界读取与摘要。
- `bootstrap.py`：唯一生产组装点。
- `features/backup`：预览、选择、恢复与对话归属映射；通过共享客户端访问 API。

## 实际验收

- 系统钥匙串使用隔离生成凭据完成写入、回读、移除。
- 浏览器真实导出 2 个知识库、11 份资料和 4 个对话，共 449461 字节，包含 5 份音视频/联合素材。
- 实际恢复为新副本后，原库保留；恢复的图片对话引用仍能展开图片与 `6583` OCR 证据。
- 在恢复副本中将文档移入回收站再恢复，资料数和片段数准确恢复。
- 自动测试覆盖迁移、拒绝访问、凭据回滚、密钥不返回、不进入备份、损坏/越界/重复 ZIP、展开超限、模型不匹配、原件/OCR/媒体/暂存往返、失败清理和对话存储配额失败。

还需完成后台作业、索引重建及跨版本迁移，以及正式安装包的系统凭据访问验证。

## 批量资料回收

活动资料支持跨页选择与全选筛选结果，点击“删除所选”后确认移入回收站。“清空全部资料”处理当前库全部活动资料，包括被筛选隐藏的条目；会暂停目录同步，旧代次的排队任务不能重新写入。资料恢复后，来源仍保持暂停，需用户显式恢复目录。

本次操作可整体撤销；离开页面或刷新后仍可在回收站逐份恢复。不会删除授权目录中的文件、对话或其他知识库。普通写入失败有补偿，断电/强制结束不保证整个批次原子恢复。暂存快照保留原件与向量，会占用磁盘；此入口没有清空回收站或永久删除。
