# 图片功能与模型分流

当前实现支持 PNG、JPEG、WebP 静态图片，每张不超过 20 MB。界面提供图片入库、本地识字、搜索结果缩略图和本地原图查看。

## 分层与数据流

- `ImageService` 只依赖图像处理、OCR 和素材存储端口。
- `PillowImageProcessor` 校验真实图片格式，处理方向、透明背景和缩略图，移除 EXIF 等元数据；单边最多 8192 像素，总像素最多 2400 万。
- `AppleVisionOCR` 使用 macOS 系统 Vision，在本机提取中文/英文文字与归一化区域位置。OCR 不可用或识别失败时明确记录状态，不编造文字。
- `KnowledgeService` 将图片向量与 OCR 文字片段写入同一模型的本地索引，并对图片搜索结果去重。入库失败会清理本次素材，删除资料会删除索引及图片文件。
- `FileAssetStore` 在应用数据目录保存规范化 PNG、缩略图和 OCR 区域记录。API 只能访问当前知识库内存在的图片，图片接口同样需要会话认证。
- `ChatService` 负责判断生成模型能力、选择证据、检查本次授权和限制图片数量。DeepSeek 适配器只负责组装请求及转发响应。

```text
图片导入 → 本地校验与 OCR → 图像 / 文字嵌入 → 本地索引与素材存储

查找图片 → 本地检索 → 缩略图 / 原图 / OCR 文字

文字问答 → 相关图片的 OCR 证据 → DeepSeek 文本生成

云端看图 → 检查模型能力与本次授权 → 最多 3 张图片 → DeepSeek 图像理解接口
```

## 两种问答方式

**本地 OCR 文字（默认）**：图片保存在本机，只把相关文字证据发送给生成模型。照片没有 OCR 文字时可以搜索、查看，但不会假装理解画面，也不会把图片向量交给文本模型。

**云端看图**：需要支持图片的模型，当前明确声明支持 `deepseek-flash` 及官方兼容别名。每个问题最多发送 3 张相关图片；提问前必须勾选本次允许发送图片。设置为云端模式不等于授权每次发送，前端每次提交后清空勾选，后端再次校验。未声明能力的模型被阻止，服务端不会自行猜测或上传。

云端图片经过方向处理、元数据移除、2048 像素长边缩放与 JPEG 压缩。请求使用 inline base64，不调用文件上传/托管接口。来源编号对应实际附图；超出预算的图片不参与这次回答。普通图片描述不能替代精确图表或数字证据。

## 独立图片识字

资料页的「选择图片识字」调用 `/api/ocr`，不加载嵌入模型、不调用 DeepSeek，也不自动入库。结果包括文字、置信度、归一化区域坐标以及识字状态；预览和结果只保存在本页面，关闭页面后释放。

## 模型准备

安装运行依赖：

```bash
uv sync --project backend --extra embedding --extra ocr --group dev
```

准备检索权重：

```bash
npm run setup:model
```

脚本仅从官方 Google Hugging Face 仓库下载固定 revision 的模型文件，验证文件大小、LFS SHA-256 或 Git blob 摘要后才标记可用。默认写入 `data/models/embeddinggemma-2/`，支持断点恢复。模型未就绪时入库/语义检索快速返回明确提示，OCR 仍可独立使用。

浏览器模式后端自动发现其数据目录中的已验证模型，桌面开发复用项目中的准备目录；其他运行目录可通过 `EDGE_EMBEDDING_MODEL_PATH` 指向该目录。推理使用本地文件，不在入库请求内隐式下载权重。模型源的离线状态不会影响生成阶段调用 DeepSeek。

## 当前边界

已实现本地 OCR 与云端图片问答的适配器；尚未实现本地通用视觉描述模型、音视频转录与生成式总结、OCR 区域叠加显示、扫描 PDF OCR 和目录持续增量索引。手动目录扫描导入与撤销授权已完成。复杂画面在默认文字模式下不能直接解读，须选择云端视觉模型或后续本地视觉适配器。

## 验证

自动测试覆盖真实 Pillow 处理、Chroma 持久化、素材权限与清理、OCR 状态、来源编号、模型能力和逐次发送授权。macOS 环境还运行真实 Vision OCR 测试。DeepSeek 图像请求使用真实 SDK 与模拟 HTTP 服务检验，尚未使用实际密钥调用云端。

浏览器界面已通过真实本地服务读取测试图片中的 `6583`。已通过本机真实 EmbeddingGemma 2 + Chroma 验收：文档排序、图片入库与 OCR 检索、768 维图片向量语义比较。该检查仅验证演示资料上的运行闭环，不代表通用检索质量基准。

文本、图片、音频和视频检索现已通过统一多模态工作台接入。图文与多图联合编码、媒体时间定位和 8K 预算见 [多模态攻略](multimodal-guide.md)。
